# 释放练习

## 何时使用

用户明确想做释放练习，或一次尚未结束的练习需要继续时使用。

## 流程

状态顺序由程序决定，不由模型决定：

1. 觉察当前感受。
2. 留意身体位置和 0 到 10 的强度。
3. 询问是否愿意允许它留在这里。
4. 询问能不能放下。不能也是完整回答。
5. 询问愿不愿意放下。不愿意或不确定时，跳过“什么时候”。
6. 只有愿意时，才询问想在什么时候放下。
7. 做一次练习后的反思，然后结束。

每次只保留一个核心问题。用户可以随时暂停、跳过或结束。

## 约束

- 这是受基础流程启发的原创引导，不是医疗程序，也不复制完整手册。
- 不要要求用户必须放下或必须释放。
- 不要承诺放下后会得到某种结果。
- 不要判断心理状况。
- 出现即时安全风险时，停止练习并给出现实支持信息。模型不得改写这段支持信息。
- 改写问句时不要加入用户的感受原文。
